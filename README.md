# Craddle Reading Foundation Online Academy

A responsive educational website for Craddle Reading Foundation Online Academy with:

- a modern homepage
- a hamburger navigation menu
- summer and kindergarten sections
- English Language courses for Primary 1 to Primary 6 at ₦3,000 each
- login and registration pages
- student and admin dashboards
- a frontend structure ready for Firebase Authentication, Firestore, and Paystack integration

## Run locally

From the project folder:

```bash
python3 -m http.server 8000
```

Then open http://127.0.0.1:8000/

## Integration notes

Replace the placeholder values in:

- firebase-config.js
- script.js

with your actual Firebase and Paystack credentials to enable full authentication, Firestore, and payment flow.
